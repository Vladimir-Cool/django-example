Django проект для обучения.

В проекте 2 страницы и работа с fдмин панелью.

На первой странице выводиться "карусель" из приложения ex_cms и информация из приложений ex_cms и price.
И форма для создания нового заказа.

После отправки формы, создаеться новый заказ в базе. Пользователь перенаправляется на вторую страницу с благодарностью.
В этот момент формируется сообщение в чат с telegram чат с ботом.

Для отправки сообщения нужен токен бота и id чата.

Так же стоит учесть что сообщение для отправки указывается в модели (telebot.models.MessageSetting) форматируется в функции отправки сообщения (telebot.service.message.send_message)

---
* Старт. Переходим в директорию проекта и качаем все зависимости.
```shell
poetry install
```
---
* В директории djangoexample/conf создаем файл `.env` и указываем там `SEСRET_KEY` для Django проекта.

Пример.
```python
SECRET_KEY = 'django-insecure-+_t-54$h%i75sh@y@95592ab9ht^ow8wa+z06)^fv$g_000000'
```
---
* Запуск проекта из директории /djangoexample
```shell
python.exe manage.py makemigrations

python.exe manage.py migrate

python.exe manage.py createsuperuser

python.exe manage.py runserver
```

Список приложений
* `ex_cms` - Приложение для карусели на HTTP странице.
  * **Модели** (Model):
    * CmsSlider - Модель для объекта карусель HTML.
  * **Представления** (views)
    * НЕТ.
  * Возможно потребуется создать директорию `djangoexample/media` для *.img файлов. Кажется Django сам этого не сделает.

* `ex_crm` - Приложение для создания "заказов".
  * **Модели** (Model):
    * Order - Модель для заказа.
    * StatusCrm - Модель статусов заказа.
    * CommentCrm - Модель для коментариев к заказу.
  * **Представления** (views)
    * index_page - Основная страница проекта.
    * thanks_pag - Страница благодарности за оставленный заказ.
  * **Форма** (Forms)
    * OrderForm - Форма для создания заказа.

* `price` - Приложение для работы с ценами.
  * **Модели** (Model):
    * PriceCard - Модель для цен на карточках.
    * PriceTable - Модель для списка услуг.
  * **Представления** (views)
    * НЕТ

* `telebot` - Приложение которое отправляет сообщение в чат с телеграмм ботом.
  * **Модели** (Model):
    * BotSetting - Модель настроек бота.
    * MessageSetting - Модель настроек сообщения.
    * ChatSetting - Модель настроек чата.
  * **Представления** (views)
    * НЕТ
  * **Сервис**
    * message.send_message - отправляет сообщение в чат. Пока что сообщение фиксировано в функции. (бот и чат указываются (ForeignKey) при создании сообщения в админ панели)
